# Rule

Always use getByRole() before considering any other locator.

## Why

getByRole() is resilient to DOM structure changes, improves accessibility compliance,
and produces more maintainable tests.

## Priority

⭐⭐⭐⭐⭐ Required

## Good

await page.getByRole('button', { name: 'Login' }).click();

## Acceptable

await page.getByTestId('login-button').click();

## Avoid

await page.locator('.btn-primary').click();

## Never

await page.locator('/html/body/div[2]/button').click();

## Exceptions

Use getByTestId() only when:
- Multiple elements share the same accessible role.
- The UI library prevents reliable accessibility attributes.
- The application intentionally exposes stable test IDs.

## AI Rule

Always attempt getByRole() first.
Fallback order:
1. getByRole()
2. getByLabel()
3. getByPlaceholder()
4. getByText()
5. getByTestId()
6. locator()
7. XPath (last resort)
